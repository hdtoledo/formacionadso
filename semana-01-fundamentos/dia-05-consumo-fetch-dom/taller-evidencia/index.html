Sistema de Inventario de Insumos Agropecuarios

Has sido contratado por la empresa ficticia AgroHuila S.A.S. en Garzón para construir la capa cliente (Frontend) que interactúa con su servidor Express. Debes programar el código JavaScript con fetch() en cada una de las 6 plantillas modulares para dar vida a la plataforma sin recargar la página.

📡 Servidor: http://localhost:3000 📦 Recurso: /api/insumos 🎨 Tailwind CSS Nativo

Instalar y Ejecutar Backend

2

Abrir con Live Server

Click derecho -> Open with Live Server

El frontend corre en el puerto :5500.

3

Programar el JavaScript

Abre cada archivo 01 a 06 y completa los bloques <script> guiados.
