Al ejecutar fetch, esta tarjeta se actualizará en tiempo real con los valores deserializados de la API.

Código JavaScript Didáctico (Fetch Nativo): 
const res = await fetch('http://localhost:3000/api/status');
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();
console.log('Servidor en línea:', data.mensaje, data.uptimeSegundos);
